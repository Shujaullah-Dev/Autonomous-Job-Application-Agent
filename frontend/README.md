# Job Agent frontend

From this directory, run `npm ci` and `npm run dev`. Open the Vite URL and choose **Explore the demo** for a complete sample journey without a backend.

Setup, architecture, API inventory, roadmap coverage, privacy limits, tests, and deployment instructions are in [the frontend handover](../docs/frontend.md).

Private live features remain blocked pending verified server ownership checks. The frontend never uses a backend development credential. Supabase Auth is optional; browser-safe configuration is listed in `.env.example`.
